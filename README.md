# 🎨 Calculadora POS de Colores

Una aplicación web interactiva tipo "Punto de Venta" (POS) para calcular presupuestos y cobros basados en un sistema de colores, utilizando "Libro Pesos" (LP) como moneda.

## 🚀 Características
- **Interfaz Moderna:** Diseño limpio, responsivo y orientado a la experiencia del usuario.
- **Cálculo en Tiempo Real:** Generación de recibo dinámico al momento de seleccionar cantidades.
- **Arquitectura Ligera:** Desarrollado en Vanilla JS (ES6) y Tailwind CSS. Sin dependencias complejas ni tiempos de compilación.

## 🛠️ Despliegue en GitHub Pages
Este proyecto está optimizado para ser desplegado instantáneamente en GitHub Pages:
1. Haz un fork o sube este repositorio a tu cuenta de GitHub.
2. Ve a la pestaña **Settings** > **Pages**.
3. En la sección "Build and deployment", selecciona la rama `main` y guarda.
4. En un par de minutos, tu calculadora estará pública en Internet.
